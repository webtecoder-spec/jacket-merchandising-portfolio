# Sazzad Hossen — Jacket & Outerwear Merchandising Portfolio

Premium single-page professional portfolio website for a garment merchandising specialist focused on jacket and outerwear product categories.

## Structure

```
jacket-merchandising-portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
│   ├── hero/
│   ├── jackets/
│   ├── process/
│   └── profile/
├── documents/
│   └── Sazzad_Hossen_CV.txt   ← Replace with real PDF
└── README.md
```

## Features

- Sticky navigation with smooth scroll
- Fully responsive (desktop / tablet / mobile hamburger)
- Subtle scroll reveal and hover animations
- Semantic HTML + SEO meta tags
- Dark premium aesthetic with gold accent
- Confidentiality-safe case studies (anonymized)

## How to use

1. Open `index.html` in a browser, or serve the folder with any static host.
2. Replace `documents/Sazzad_Hossen_CV.txt` with your real CV PDF and update the download links.
3. Update contact email, phone and LinkedIn URL in the Contact section.
4. Optionally add more jacket product photos under `images/jackets/`.

## Design notes

- Palette: near-black background, charcoal surfaces, soft gold accent
- Fonts: Inter + Manrope (Google Fonts)
- No confidential PO numbers, prices, tech packs or internal documents are included
